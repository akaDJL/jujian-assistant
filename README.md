# 居间小助手 · 公开联系人挖掘（合规版）

面向**工程居间人**的轻量工具：输入一批目标企业 → 自动突破搜索引擎反爬 →
从**搜索引擎 + 企业库 + 社媒公开源**抓取公开网页 → 抽取业务部门联系人 / 电话 / 邮箱 / 关键人
→ 表格展示 + CSV 导出。**全程内置合规护栏**，把「合法」做成可执行的代码。

## 技术栈
- Python 3.13（managed）+ FastAPI + uvicorn
- **curl_cffi**（TLS 指纹伪装 `impersonate=chrome`，专治反爬，无需浏览器）
- BeautifulSoup + lxml（解析与抽取）
- `compliance.py`（合规护栏）、`social.py`（社媒适配器），与 `scraper.py` 解耦

3. **合规护栏（compliance.py，强制前置）**——详见下方「合规边界」。

## 用法
1. 企业名单框：每行一家，可批量（如 10 家一起挖）。
2. 关注部门：选预设 chip 或自填（环保工程部 / EPC项目部 / 采购部 / 招标联系人…）。
3. 搜索引擎：默认 Sogou（中文企业结果最相关）；Sogou 偶发反爬时自动回退 Bing → Baidu。
4. 社媒来源：勾选要补充的社媒（微信默认勾选；微博/抖音/小红书为 ToS 受限的尽力而为源）。
5. 点「开始挖掘」→ 结果表按相关度/含手机/低风险排序 →「导出 CSV」（含运营商/场景/风险/法律基础/采集时间列）。
6. 拒收名单：任何个人要求「不联系/删除」的号码，在面板加入，后续永久屏蔽。

## 反爬策略（实测）
- TLS 指纹伪装（`impersonate=chrome`）过 JA3/TLS 检测，无需浏览器。
- 公司名加引号精确匹配 + 多意图查询（联系方式 / 项目对接人 / 社媒业务号）。
- 多引擎回退 + SERP 失败重试。
- 受控并发（Semaphore=4）+ 随机延时 + **per-host 礼貌间隔 2.5s**。
- 置信度过滤 + 噪声丢弃：命中公司名的页面标「高」，百科/UGC/政府门户噪音默认过滤。
- 可选代理：设环境变量 `SCRAPER_PROXY=http://host:port` 换 IP。

## 合规边界（务必遵守，已代码化）
本工具依据《个人信息保护法》(PIPL) 设计，合规不是口号而是强制逻辑：

| 护栏 | 实现 |
|---|---|
| **robots.txt 遵守** | 目标站点 `Disallow` 的 path 一律不抓（带 24h 缓存） |
| **礼貌抓取** | per-host 最小请求间隔 2.5s，不压垮对方服务器 |
| **拒收名单 (DNC)** | 个人要求「不联系/删除」的号码永久屏蔽、永不返回 |
| **采集审计** | 每条手机号哈希落盘（时间/来源/场景/风险/法律基础），不含明文 |
| **用途声明** | 使用前必须确认《使用须知》，否则 `/api/search` 返回 403 |
| **上下文分级** | 企业业务线(低) / 商务场景个人号(中) / 未知个人(高,默认不采) |

- **法律基础**：手机号属个人信息。本工具依 PIPL 第 13 条第 6 项 + 第 27 条，在「合理范围」内
  处理个人「自行公开或其他已合法公开」的信息；**个人明确拒绝的，停止处理并删除**（拒收名单即此机制）。
- **范围**：本次按你的选择纳入「商务场景下自行公开的个人手机号」，但**无任何商务场景佐证的纯个人号
  默认不采集**（需显式开启「包含高风险个人号」且自担责任）。
- **红线（本工具不做的）**：不突破任何平台的登录墙 / 付费墙，不规避反爬验证码，
  不转售、不骚扰、不诈骗。微博/抖音/小红书等源严格遵守其 ToS，被拦即止。
